- For compaction, persist trusted `beforeCompact` task/owner/range evidence. The first genuinely hook-bound summary validates the current `summarize` checkpoint and establishes its prepared tuple and semantic request digest. On later unbound summary requests, require this exact prior mapping and tuple/digest plus exactly one eligible model producer. Ignore timestamp-only summarizer changes, not model-visible content.

Deny ambiguous or foreign producers, unsupported versions/background paths, missing actual generation binding, phase/owner/range/request mismatch and absent first-summary association. Denying the last case is a documented conservative availability limit, not permission to guess a task.
- One mandatory provider lane covers association, asynchronous preparation, durable admission, final rereads and actual dispatch initiation. Register competing callbacks synchronously. Recheck task, mapping, run epoch, lifecycle authority and live/durable fences after awaits. Response waiting happens outside the lane with cooperative cancellation; Stop must not queue behind this lane.
- Identify the logical request by retained task plus prepared cutoff/range/configuration. Record Pi checkpoint attempt separately from actual dispatch attempt and host invocation. A same-checkpoint callback is not automatically safe replay. An unresolved original effect denies before dispatch across any reopen, independently of successful correlation. A known completed error with matching Pi retry evidence may make a separately recorded spending attempt.
- All provider, compaction, tool and future metadata calls remain mandatory-guarded. No stock bypass. Public records establish correlation only; Pi alone schedules continuation. Preserve the first red signal probe and all earlier evidence unchanged.
