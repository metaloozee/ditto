# Keep remembered preferences with their intended audience

A preference given to a specialist applies to that bot. When the owner explicitly asks for it to apply across the team, the specialist can pass the instruction to Ditto to update the shared profile. This lets the owner give Writer a preference for short updates without also constraining Researcher’s reports.

A correction becomes the current memory for that audience from the next turn, including after compaction or a model change. The original conversation remains searchable so the owner can ask what they said at the time.
