# Verify delegated work against the owner’s request

A specialist’s completion signal or final message proposes a result. Ditto marks the task complete only after checking the result against the owner’s request. This lets Ditto recover a lost completion signal without repeating finished work, and return an incomplete result to the same specialist with the missing requirement.

Use a deterministic check when it establishes the requested outcome. When verification requires judgment, Ditto or a reviewer evaluates the work against the owner’s criteria and evidence.

Cancellation stops unfinished work throughout the task tree and preserves published deliverables. Ditto reports confirmed external effects and identifies any outcome that remains unknown. Cancellation alone authorizes neither a retry nor an attempt to undo an external action.
